# homebrew-tap

This tap is no longer maintained. Its `cookcli` formula is stuck at v0.10.0.

Install the current CookCLI from Homebrew core instead:

```
brew install cookcli
```

If you installed it from this tap, switch with:

```
brew uninstall cooklang/tap/cookcli
brew untap cooklang/tap
brew install cookcli
```

Other install options: [cooklang.org/cli/download](https://cooklang.org/cli/download/).
